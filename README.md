"# ai_quiz_app" 
Added Minimum Viable product(MVP) 
1]A very minimal frontend just to show core working of app
2]Moderate working backend with strong core functionalities

Working 
1]User will see two options Create Game and Join Game 
   CREATE GAME 
     *PLAYER NAME 
     *TOPIC  ex:sql,java,c
   JOIN GAME 
     *PLAYER NAME 
     *GAME ID
2]One who Create a game 1st will be assigned as Host--Player 1
3]When a Game is Created a Gameid is Generated to invite multiple players
4]With a Gameid another player can join in the quiz Game,Then Host will start the game 
5]Quiz will be generated by AI 
6]Each Player will answer the questions simultaneously and seperately
7]When Quiz is Submitted,evaluation happens and winner will be annoounced.
